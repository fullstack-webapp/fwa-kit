# Source provenance

FWA Kit began as a clean public cut of privately developed source material from `@zgq354/fwa-app-shell-sdk@0.1.0-beta.21`.

The fixed migration base was:

- Git revision: `4cc5ed106361bdd5838d6ee4ca135ed81835fd6b`
- Git tree: `b9ee188f6fd2351fa1b174633babe0857d04ab67`

The imported source was reorganized into the FWA Kit monorepo and migrated from the App Shell vocabulary to FWA Local Edge before publication. The public repository starts with independent history; the private development history is not part of this repository.

The clean cut excludes private consumer and deployment records, operator configuration, credentials, package-publishing workflows, generated SDK bundles, and unrelated workspace material. The public repository, its tags, and its release artifacts are the authority for FWA Kit after the cut.

Imported code and subsequent FWA Kit contributions are provided under the repository's MIT license.
